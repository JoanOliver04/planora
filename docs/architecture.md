# Architecture

Next.js App Router uses Server Components by default and client islands for completion, theme and navigation interactions. `next-intl` owns locale routing and structured messages. Supabase SSR manages cookie sessions. PostgreSQL remains the authority for all user data. Pure recurrence functions derive finite ranges on demand; no future occurrence rows or cron jobs are required. Zod schemas are shared at trust boundaries.

Focus lives under `src/features/focus/*`: pure domain (state machine, engine, plans, goals, analytics), server actions for persistence, and client runtime (`FocusRuntime` / `useFocusSession`) for the timer UI. Elapsed time is derived from interval timestamps; the display ticker never writes to the database. Cross-tab sync uses BroadcastChannel with localStorage fallback; multi-device drift uses light polling. Offline continuation queues idempotent transitions for known sessions only. Portable backups (schema v4) round-trip Focus entities through the existing atomic restore RPC.
