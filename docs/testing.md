# Testing

Vitest covers recurrence bounds, weekdays, intervals, month ends, formatting, day parts, timezone week boundaries, validation, task-form progressive disclosure, and the Focus domain (timer engine, cycles, plans, goals, analytics, offline queue, multi-tab sync, keyboard a11y, onboarding, backup v5). React Testing Library is configured for client components. Playwright covers protected-route redirects (including `/focus` → login), language switching, mobile login, backup restore and the authenticated Focus lifecycle (preset, task link, pause/reload/resume, distraction, complete, export/restore). CI starts an isolated local Supabase instance and applies every migration before E2E, so authenticated desktop, mobile and WebKit journeys cannot silently skip for missing credentials. Never add an auth bypass to production code.

The database integration suite also runs in CI. It verifies ownership, resource bounds, atomic restore and account deletion under the restricted Auth service role. Every SQL fixture rolls back. The browser accessibility matrix covers 80 public screens, 32 private screens including completed-task statistics, six custom accents in both themes, 200% text, OAuth recovery and pointer-based ordering in each browser project. Lighthouse checks three mobile runs per route and blocks regressions below 90 performance, 100 accessibility or 100 best practices; landing SEO must remain 100. Demo pages intentionally opt out of indexing.

Programmatic file downloads are intercepted in `tests/data-tools.test.tsx`. JSDOM does not implement document navigation, so download tests must assert the generated object URL and anchor click without invoking its native navigation behavior.
