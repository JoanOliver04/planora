# Assets

Imágenes de marca utilizadas por Planora:

- logo_modo_claro.png: logo mostrado con el tema claro.
- logo_modo_oscuro.png: logo mostrado con el tema oscuro y en GitHub.
- `logo.ico`: favicon mostrado en la pestaña del navegador.

Los archivos se sirven desde la raíz de la web. Por ejemplo,
`public/assets/logo.ico` se utiliza como `/assets/logo.ico`.
