# Assets

Imágenes de marca de Planora.

- `planora-logo-light.webp`: logo mostrado con el tema claro.
- `planora-logo-dark.webp`: logo mostrado con el tema oscuro y en GitHub.
- `planora-mark.webp`: símbolo de la portada, el acceso, la carga y las vistas previas al compartir enlaces.
- `notification-badge.png`: versión monocroma del símbolo para notificaciones.
- `../icon-192.png` y `../icon-512.png`: iconos de instalación. El de 192 px también se usa en notificaciones.
- `../icon-maskable.png`: icono de instalación para lanzadores con recorte.
- `../apple-touch-icon.png`: icono para la pantalla de inicio de Apple.
- `../../src/app/favicon.ico`: favicon con tamaños de 16 a 64 px, servido en `/favicon.ico`.
